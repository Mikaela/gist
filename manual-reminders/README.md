# Reminders for the difficult part of manuals

Some devices are simple to use, some are not. Some have only a specific part
what is difficult and I keep forgetting and postponing. Thus this directory.

I initially thought to only note how I got it working, but
[Silvercrest Sound Mini](silvercrest-sound-mini.md) was surprisingly future
wonderer friendly and thus I ended up documenting the {model,IAN} number and
where to find the official manual and as I ended up quoting directly, I used
markdown quotes for that.
